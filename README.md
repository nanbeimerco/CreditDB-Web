# CreditDB for Web

アニメ作品・制作陣評価 Web図鑑

全5,452作品・22,896名の制作陣・声優データをオフライン完結・ミリ秒単位で高速検索・閲覧・分析できる Material 3 準拠の Web 図鑑です。

## 主な機能
- **作品DB**: 5,400作超のアニメ作品を偏差値・評価・年代・ジャンルで検索・ソート
- **制作・声優**: 監督・脚本・演出・アニメーター・声優の参加作品タイムライン年表と評価集計
- **Tier表**: 直感的なドラッグ＆ドロップ並び替え、アニメーション挿入スロット、スタッフ親和性診断、高解像度画像エクスポート (FHD / 2K / 4K)
- **オフライン完結**: SQLite (sql.js / WASM) + IndexedDB による完全ローカル高速データベース駆動

## 開発環境
- Node.js 20+
- React 18 / TypeScript / Vite / Tailwind CSS
